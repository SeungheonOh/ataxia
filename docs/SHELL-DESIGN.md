# Shell design

The compositor uses a minimal light interface. White panels, square corners,
clear text and a thin border establish hierarchy; shadows, decorative gradients,
bouncing controls and oversized promotional copy do not.

| Role | Value |
| --- | --- |
| Panel | `#ffffff` |
| Input surface | `#f7f8f9` |
| Hover / pressed | `#f0f2f4` / `#e3e7eb` |
| Border | `#d4d8dc`, 1 logical pixel |
| Text / secondary text | `#24282d` / `#626a73` |
| Selection | `#244ebc` on `#eaf0ff` |
| Caution / destructive action | `#9a651b` / `#ad343f` |
| Typeface | DejaVu Sans |
| Text | 12–13 logical pixels; headings 14–15 |
| Spacing | 4-pixel increments; panel padding 16; compact padding 12 |
| Controls | 32-pixel height; compact controls 28 |
| Corners / shadows | Square / none |

Use a common baseline for a row of controls. Keep hit areas stable on hover and
press. Use explicit width for scrolling children of RmlUi flex layouts; otherwise
an overflowing child can shrink to its minimum text width. Long content scrolls
inside a panel without moving its close, pause or stop controls offscreen.

The 44-pixel status bar is anchored to the bottom edge. Applications appear in a
searchable list. Battery details, agent access cards, notes, layout controls,
window controls, notifications and the keyboard launcher use the same palette.
An empty agent access panel stays hidden. User-created or third-party application
content remains under that application's control; its client-side decoration is
not the compositor's shell theme.

Current native previews are generated by `tests/rmlui-status-bar-gles.py`,
`tests/rmlui-shell-gles.py` and `tests/computer-use-gles.py`. They cover 320–1320
logical pixels, 2× scaling, real keyboard/callback delivery and settled rendering.
The six built-in Slint scenes were also inspected with their native renderer.

The September 16, 2026 live update replaced eight native Slint scenes in place
and reloaded the RmlUi documents. It preserved the World, all 20 applications,
window geometry, seats and focus. General tests, shell World tests and the
computer-use suite passed. UI rendering is unchanged while idle, apart from the
existing clock maintenance and focused text-input caret.
